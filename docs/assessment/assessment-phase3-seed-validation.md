# 心理测评模块阶段三说明

## 范围

- 固化 `PHQ-9` 与 `GAD-7` 标准量表种子数据。
- 将量表题目、选项、评分规则全部落库。
- 通过幂等初始化保证重复启动不产生重复种子。
- 通过真实样例验证低、中、高三个评分档位。

## 种子数据定义

### 标准量表

- `PHQ9`
  - 题目数：9
  - 题目页大小：3
  - 阈值兼容字段：`0 / 5 / 10`
  - 评分规则：
    - `LOW`: `0-4`
    - `MEDIUM`: `5-9`
    - `HIGH`: `10-27`

- `GAD7`
  - 题目数：7
  - 题目页大小：3
  - 阈值兼容字段：`0 / 5 / 10`
  - 评分规则：
    - `LOW`: `0-4`
    - `MEDIUM`: `5-9`
    - `HIGH`: `10-21`

### 标准选项模板

- `A`: 完全没有，`0` 分
- `B`: 好几天，`1` 分
- `C`: 一半以上时间，`2` 分
- `D`: 几乎每天，`3` 分

## 初始化策略

- 启动入口：`DataInitializationRunner`
- 幂等方式：
  - 按量表编码同步 `mental_scale`
  - 按 `(scale_id, question_no)` 同步 `mental_scale_question`
  - 按 `(question_id, option_code)` 同步 `mental_scale_option`
  - 按 `(scale_id, level_code)` 同步 `mental_scale_rule`
- 启动后立即校验：
  - 量表题目数量是否与标准一致
  - 每题是否存在 4 个标准选项
  - 每个量表是否存在 3 条评分规则

## 验证矩阵

### PHQ-9

- 低分档样例：`0` 分，总分 `0`，等级 `LOW`
- 中分档样例：前 `5` 题选择 `1` 分，其余 `0` 分，总分 `5`，等级 `MEDIUM`
- 高分档样例：前 `4` 题选择 `3` 分，其余 `0` 分，总分 `12`，等级 `HIGH`

### GAD-7

- 低分档样例：`0` 分，总分 `0`，等级 `LOW`
- 中分档样例：前 `5` 题选择 `1` 分，其余 `0` 分，总分 `5`，等级 `MEDIUM`
- 高分档样例：前 `4` 题选择 `3` 分，其余 `0` 分，总分 `12`，等级 `HIGH`

## 验收要求

- `/api/scales` 返回 `PHQ9` 与 `GAD7`
- `/api/scales/{id}` 返回 3 条评分规则
- 分页题目接口返回标准题目数和标准选项分值
- 六组样例提交后，报告总分和等级全部命中预期
- 重复冷启动后，量表编码、题目数、规则数保持稳定

# 纯后端测试验收指南

## 1. 准备环境

1. 确保 MySQL 与 Redis 已启动。
2. 导入验收数据：

```powershell
powershell -ExecutionPolicy Bypass -File E:\Store\SDJZU\毕设\JQPro\scripts\import-acceptance-data.ps1
```

3. 启动后端：

```powershell
powershell -ExecutionPolicy Bypass -File E:\Store\SDJZU\毕设\JQPro\scripts\start-backend.ps1 -ForceRestart
```

4. 后端地址：`http://127.0.0.1:8080`

## 2. 默认账号

- 学生：`20230001 / Jqpro@123`
- 咨询师：`teacher01 / Jqpro@123`
- 管理员：`admin / Jqpro@123`
- 隔离学生：`20230002 / Jqpro@123`

## 3. 推荐验收顺序

### 3.1 自动化全量回归

```powershell
powershell -ExecutionPolicy Bypass -File E:\Store\SDJZU\毕设\JQPro\scripts\full-acceptance.ps1
```

预期结果：输出 JSON，包含 `phase1Auth`、`phase1Assessment`、`phase2`、`phase3`、`phase46`、`phase7` 六段结果，且不抛出异常。

### 3.2 关键接口手工验收

#### 1. 学生登录

```bash
curl -X POST http://127.0.0.1:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "account": "20230001",
    "password": "Jqpro@123"
  }'
```

预期结果：返回 `code=200`，`data.token` 非空。

#### 2. 查询并更新学生档案

```bash
curl http://127.0.0.1:8080/api/student/profile/me \
  -H "Authorization: <student-token>"
```

```bash
curl -X PUT http://127.0.0.1:8080/api/student/profile/me \
  -H "Authorization: <student-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "nickname": "Backend Student",
    "gender": "FEMALE",
    "college": "软件学院",
    "major": "软件工程",
    "grade": "2023",
    "avatarUrl": "https://example.com/avatar/backend-student.png"
  }'
```

预期结果：档案返回中包含更新后的 `avatarUrl`，审计日志可查询到 `PROFILE_UPDATE`。

#### 3. 完成一次量表提交并查看报告

1. 获取量表列表：

```bash
curl http://127.0.0.1:8080/api/scales \
  -H "Authorization: <student-token>"
```

2. 创建草稿：

```bash
curl -X POST http://127.0.0.1:8080/api/scales/1/sessions/draft \
  -H "Authorization: <student-token>"
```

3. 获取题目：

```bash
curl http://127.0.0.1:8080/api/scales/sessions/<sessionId>/questions \
  -H "Authorization: <student-token>"
```

4. 保存答案并提交：

```bash
curl -X PUT http://127.0.0.1:8080/api/scales/sessions/<sessionId>/answers \
  -H "Authorization: <student-token>" \
  -H "Content-Type: application/json" \
  -d '{"answers":[{"questionId":1,"optionId":1}]}'
```

```bash
curl -X POST http://127.0.0.1:8080/api/scales/sessions/<sessionId>/submit \
  -H "Authorization: <student-token>"
```

5. 查询报告：

```bash
curl http://127.0.0.1:8080/api/student/reports \
  -H "Authorization: <student-token>"
```

预期结果：可获得 `reportId`，并在报告详情中看到风险等级、AI 解读、推荐资源、是否建议预约。

#### 4. 学生 AI 会话与匿名预约

1. 创建 AI 会话：

```bash
curl -X POST http://127.0.0.1:8080/api/student/ai-sessions \
  -H "Authorization: <student-token>"
```

2. 发送消息：

```bash
curl -X POST http://127.0.0.1:8080/api/student/ai-sessions/<sessionId>/messages \
  -H "Authorization: <student-token>" \
  -H "Content-Type: application/json" \
  -d '{"content":"最近学习压力很大"}'
```

3. 查询可预约时段：

```bash
curl http://127.0.0.1:8080/api/student/appointments/slots \
  -H "Authorization: <student-token>"
```

4. 发起预约：

```bash
curl -X POST http://127.0.0.1:8080/api/student/appointments \
  -H "Authorization: <student-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "slotId": 1,
    "topicSummary": "希望预约一次咨询",
    "anonymousAlias": "海盐同学"
  }'
```

预期结果：返回预约记录，学生只能看到匿名业务字段；管理员审计中可见 `APPOINTMENT_CREATE`。

#### 5. 咨询师接单与查看学生数据

1. 咨询师登录并获取 token。
2. 查询预约列表：

```bash
curl http://127.0.0.1:8080/api/counselor/appointments \
  -H "Authorization: <counselor-token>"
```

3. 接单：

```bash
curl -X POST http://127.0.0.1:8080/api/counselor/appointments/<appointmentId>/accept \
  -H "Authorization: <counselor-token>"
```

4. 查看学生报告：

```bash
curl http://127.0.0.1:8080/api/counselor/students/1/reports \
  -H "Authorization: <counselor-token>"
```

5. 查看学生 AI 会话：

```bash
curl http://127.0.0.1:8080/api/counselor/students/1/ai-sessions \
  -H "Authorization: <counselor-token>"
```

预期结果：仅能查看已绑定学生数据；未绑定学生访问返回业务错误。

#### 6. 资源与后台治理

1. 管理员登录并获取 token。
2. 查询用户管理：

```bash
curl http://127.0.0.1:8080/api/admin/users \
  -H "Authorization: <admin-token>"
```

3. 查询量表管理：

```bash
curl http://127.0.0.1:8080/api/admin/scales \
  -H "Authorization: <admin-token>"
```

4. 查询资源管理：

```bash
curl http://127.0.0.1:8080/api/admin/resources \
  -H "Authorization: <admin-token>"
```

5. 查询统计总览：

```bash
curl http://127.0.0.1:8080/api/admin/statistics/overview \
  -H "Authorization: <admin-token>"
```

6. 查询审计日志：

```bash
curl "http://127.0.0.1:8080/api/admin/audit-logs?page=1&pageSize=10" \
  -H "Authorization: <admin-token>"
```

预期结果：管理员可执行治理类操作并查看审计；学生访问这些接口返回 `403`。

#### 7. 权限与安全回归

```bash
curl http://127.0.0.1:8080/api/admin/users \
  -H "Authorization: <student-token>"
```

预期结果：返回 `403`。

```bash
curl http://127.0.0.1:8080/api/resources
```

预期结果：未登录返回 `401`。

## 4. WebSocket 验收

聊天室建议使用 Postman、Apifox、Insomnia 或 `websocat` 连接：

```text
ws://127.0.0.1:8080/ws/consult-chat?appointmentId={appointmentId}&token={token}
```

发送体：

```json
{
  "content": "你好，我想继续刚才的话题"
}
```

预期结果：双方连接成功后都能收到实时消息；超时结束的预约对应聊天室会被自动封存。

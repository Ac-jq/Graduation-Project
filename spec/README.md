# Spec 文档总览

`spec/` 是本仓库的权威文档目录，统一收口需求、阶段方案、后端设计与接口文档。

目录约定如下：

- `01_Requirements/`
  - 事实型文档，放任务书、PRD 这类上游输入
- `02_Proposals/`
  - 阶段性文档，放阶段任务、执行清单、测试数据与验收指南
  - 每个阶段使用独立文件夹管理，文件夹内至少包含 `阶段任务.md` 和 `todo.md`
- `03_Design/`
  - 长期有效的设计与约束文档
  - `backend/` 放后端架构、数据库、错误码、PRD 核对清单等核心设计
- `04_api/`
  - 纯后端接口文档

补充约定：

- 小粒度实现文档不迁移到 `spec/`，避免把权威文档和过程性文档混在一起。
- 若仓库继续保持纯后端交付状态，不再新增前端设计文档目录。
